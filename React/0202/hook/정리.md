# 리엑트 훅

## 리엑트 훅은 왜 훅이라고 불리는가

훅은 보통 낚시에서 쓰이는 도구를 의미합니다. 미끼를 걸어 물고기를 잡는 데 사용하죠. 

리엑트 훅은 왜 이런 이름을 사용할까요? 리엑트 훅은 함수입니다. 이 함수를 호출되면 리엑트의 기능을 끌어와서 사용할 수 있게 해주는 함수입니다. 즉, 리엑트의 기능을 '낚아채는' 도구라는 의미에서 훅(hook)이라는 이름이 붙여졌습니다.

## 일반 함수와는 어떻게 다른가요

일반 함수는 호출하면 함수의 기능만 수행합니다. 그러나 리엑트 훅은 호출되면 리엑트의 상태 관리, 생명주기 관리 등 다양한 기능을 사용할 수 있게 해줍니다. 다양한 기능들이 줄줄이 연결되어 있다는 점이 다른겁니다.

## 종류

* useState: 리렌더링, 변수 유지
* useEffect: 변수 감시
* useRef: DOM 접근, 변수 유지
* useContext: Context API 사용
