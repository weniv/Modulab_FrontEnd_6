다음 URL 설계를 구현하세요.

- / : 홈 화면을 보여줍니다.
- /blog : 블로그 글 목록을 보여줍니다.
- /blog?category=카테고리명&page=페이지번호 : 특정 카테고리의 블로그 글 목록을 페이지네이션과 함께 보여줍니다. (예: /blog?category=tech&page=2)
- /blog/:id : 특정 블로그 글의 상세 내용을 보여줍니다. (예: /blog/123)
- /about : 사이트 소개 페이지를 보여줍니다.
- /contact : 연락처 페이지를 보여줍니다.
- /products : 제품 목록을 보여줍니다.
- /products/:id : 특정 제품의 상세 정보를 보여줍니다. (예: /products/456)
- /lectures : 강의 목록을 보여줍니다.
- /lectures/sw : 소프트웨어 강의 목록을 보여줍니다.
- /lectures/ai : 인공지능 강의 목록을 보여줍니다.
- /lectures/data : 데이터 사이언스 강의 목록을 보여줍니다.
